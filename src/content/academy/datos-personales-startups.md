La mayoría de startups descubre la Ley 29733 cuando un cliente corporativo les manda un
cuestionario de debida diligencia, o cuando les llega una notificación. Las dos son malas
fechas para empezar.

El taller recorre el camino mínimo de cumplimiento para una empresa pequeña: qué datos
estás tratando sin haberlo notado, cómo se redacta un consentimiento que sirva, cuándo
hace falta inscribir un banco de datos, y qué firmar con los proveedores que tocan tu
base de usuarios.

## Qué te llevas

- El inventario de tratamiento de datos de tu propia empresa, llenado durante el taller.
- Modelos de cláusula de consentimiento y de aviso de privacidad.
- El procedimiento para inscribir bancos de datos ante la APDP, paso a paso.

## Requisitos

Traer una lista aproximada de los formularios, herramientas y proveedores donde viven
los datos de tus usuarios. Sin eso, el ejercicio principal no se puede hacer.
